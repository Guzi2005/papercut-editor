# 矢量绘图

左栏的「矢量绘图」是一级入口，上方工具栏与右键菜单提供两种二级模式：

- **极简模式**：保留原锚点微调工具及 A 快捷键，选择切口后拖动顶点。原来的笔画重建方式不变。
- **精细模式**：编辑当前图层的纸片外轮廓、贴花、切口或手绘路径。使用上方路径下拉框切换对象，也可点击其他路径边缘。图层及所属组锁定、隐藏时不可编辑。

精细模式中，点击节点选中，Shift 加选，Ctrl+A 全选当前路径节点。拖动节点时控制柄随动；Ctrl 约束节点移动方向或将控制柄角度吸附到 15°；Alt 独立调整控制柄。支持尖角、平滑、对称节点，插入节点、删除节点和将后续线段变直。双击线段在其中点插入节点，插入使用 de Casteljau 分割，保持原曲线形状。右键节点提供同一组操作。

拖动实时预览纸片，每次释放只产生一条撤销记录。Esc、指针取消或窗口失焦取消当前预览。闭合轮廓至少保留三个节点，开放路径至少保留两个。节点约束保存在项目文件中。圆弧会转换成三次贝塞尔近似；复合路径的内环和闭合状态保留。

所有模式共用项目、图层、撤销和 Godot 导出。精细模式编辑笔画轮廓后会清除旧的程序化笔画参数，防止后续变换重新生成旧形状；颜色、纹理、图层和物件标识、枢轴、插槽不变。

这是应用内的 SVG 矢量编辑实现，交互借鉴 Inkscape；没有嵌入 Inkscape 桌面程序或复制其源码。本阶段不包含完整 Inkscape 功能、SVG 文件导入、节点断开/连接或独立钢笔工具。
