# 矢量绘图

左栏「矢量绘图」进入同一画布的三种二级工具：

- **钢笔**：点击落角点；按住拖动建立贝塞尔切线；点击起点闭合，Enter 完成开放路径，Backspace 回退节点，Esc 取消。Ctrl 将方向约束到 15°，Alt 拖动可断开另一侧手柄。闭合路径遵循刻纸／贴花设置，开放路径作为笔迹。
- **节点**：编辑纸片外轮廓、贴花、切口及手绘路径。直接点选路径边缘，也支持拾取其他未锁定图层的路径。上方下拉框可精确切换。
- **极简模式**：保留 A 快捷键，拖动切口顶点；进入工具不改写几何，移动节点时保留原有曲线控制柄，避免自动变成尖角。

节点工具中，点击节点选中，Shift 加选，Ctrl+A 全选当前路径节点。拖动节点时控制柄随动；Ctrl 约束移动方向或手柄角度；Alt 拖动节点可建立切线，Alt 拖动手柄可独立调整。直接拖动线段弯曲；双击线段在点击位置附近插入节点，以 de Casteljau 分割保持原曲线形状。支持尖角、平滑、对称节点，以及插入／删除节点、后续线段变直；右键节点提供相同操作。

节点拖动实时预览，每次释放只产生一条撤销记录。Esc、指针取消或窗口失焦取消当前预览。轮廓至少保留两个节点，支持两节点闭合曲线。节点约束保存在项目文件中；圆弧转换成三次贝塞尔近似，复合路径内环与闭合状态保留。

所有模式共用项目、图层、撤销和 Godot 导出，图章原稿也使用同一套工具。直接编辑笔画轮廓后清除过时的程序化笔画参数；对称路径保留源曲线与复制变换，修改源节点会同步更新当次笔画的对称副本。

这是应用内的 SVG 矢量编辑实现，交互借鉴 Inkscape，没有嵌入桌面程序或复制其源码。尚不包含全部 Inkscape 功能，例如节点断开／连接和完整 SVG 语义往返。
