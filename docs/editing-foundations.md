# 编辑基础与交互约定

## 画布与对称

图层栏底部依次为参考图、画布设置。参考图固定置底，仅辅助临摹与取色，可调位置、比例、透明度和可见性，不参与导出。

画布设置包含尺寸、显示背景、纹理、实时对称。轴对称支持调整轴数和角度；中心对称默认两份（180°），可增加重复数。轴／中心可在画布上拖动、隐藏或锁定，设置随文档保存。不同文档及图章原稿分别持有自己的对称设置。

剪纸、几何、手绘、钢笔、图章和织带均沿当前设置实时预览与生成。每次笔画保留自己的源曲线和复制变换；之后移动画布轴不会改动已有作品。水平／垂直翻转围绕选择内容中心进行，镜像复制围绕画布当前轴或中心进行。

## 绘制组、物件与遮挡

绘制组是辅助编辑集合，可折叠、隐藏、锁定、整组选取与变换；Item（物件）保存游戏资产身份、原点、挂点和套装类别。两者各自独立，一张图层可同时属于一个绘制组和一个物件。

图层的堆叠视图显示唯一的全局遮挡顺序，结构视图按绘制组展示成员。组合、解组、转为物件均保留图层 ID 和遮挡顺序。组转为物件的命令会明确说明重新分配所含部件的物件归属。目前绘制组为一层结构，每张图层只有一个绘制组父级。

## 属性和快捷键

名称和数值默认以文字显示；双击或 Enter／F2 才出现输入框。数值支持滚轮和横向拖动，Shift 加大步进。Enter／失焦提交，Esc 放弃输入；一次连续调值只产生一条撤销记录。搜索、新建和导出等表单保留直接输入。

- Delete／Backspace：删除选中图层；节点工具优先删除选中节点，输入框保持文字编辑行为。
- Ctrl+C／Ctrl+V：复制／粘贴图层，支持同一编辑器会话内跨文档。剪贴板保存独立快照及所需图片布料；整组和完整物件保留相应元数据。它不是系统级图层剪贴板。
- Ctrl+D：立即生成副本。
- Ctrl+G／Ctrl+Shift+G：组合／解除绘制组。
- Ctrl+Z／Ctrl+Shift+Z：撤销／重做。

设置中的「工作模式标签」默认关闭，打开后在现有工具栏高度内显示绘制／编排／资产。三个入口共享画布、选择与撤销历史。

## 后续手感改进

- 图层／物件、堆叠／结构两组切换仍有入口层次；应在持续使用后评估是否合为一处视图选择。
- 画布设置展开较长，可进一步采用只展开一个属性区的检查器，保留常用尺寸与对称摘要。
- 钢笔可以继续补齐端点吸附、延续已有路径、节点框选、清晰的完成／取消提示和临时节点工具切换。
- 变换目前以画布手柄、翻转和镜像命令为主，仍需统一位置／尺寸／角度的紧凑检查器。
- 大型作品中的路径拾取和较多对称副本需要继续进行性能与高 DPI／触控笔实测。

这些属于下一轮交互完善；不能据此宣称已达到完整专业矢量软件的覆盖程度。
