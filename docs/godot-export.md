# Godot 资产导出

在「文件 → 导出到 Godot」选择资源目录和纹理倍率。ZIP 解压到 Godot 工程根目录，打开导出的 `_overview.tscn` 可核对整张画布；`items/*.tscn` 是可独立使用的物件场景。

- 每张纸片对应一个 Sprite2D；位置已补偿裁切边界、物件原点和纹理倍率。
- 部件使用绝对 z_index，避免改变物件父节点层级后破坏跨物件遮挡。需要整体移动深度时，应修改部件的 z_index。
- 挂点是 Marker2D，保留 `weave_socket_id` 元数据；部件保留 `weave_layer_id`。
- 建议通过 Godot 的继承场景添加脚本和碰撞体，重新导出时覆盖生成的基础资源。
- 参考图不参与导出；可编辑源文件一并放进 ZIP。

导出前检查资源路径、重复归属、缺失部件、原点和挂点坐标、深度范围。排除隐藏或未归组纸片时会显示提示。渲染前限制单张贴图最长边 8192 px、总像素 3200 万，超限时降低倍率或拆分部件。

混合模式仍然按同物件下方部件烘焙，不能在 Godot 动画过程中动态重新混色。
