# 剪纸编辑器

面向 Weave and Wander 与 Godot 4 的矢量剪纸资产编辑器。

支持剪纸、笔刀、几何形、手绘、色块选取、深度层与物件分组、纹样与纸张质感、项目存档，以及 SVG、PNG 和 Godot 场景导出。

## 本地运行

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

打开终端显示的本地地址，默认端口为 3000。

```sh
npm test
npm run lint
npm run build
```

## Godot 资产

通过「文件 → 导出到 Godot」生成 ZIP，解压到 Godot 工程根目录。
导出包包含独立物件场景、部件贴图、挂点、总览场景、资产清单与可编辑源文件。

详见 [Godot 导出说明](docs/godot-export.md)。

## 图章与纹样

左栏「纹样」打开右栏素材库；顶部「笔刷设置」打开可拖动、折叠的配方工作台。内置矢车菊格子、蓝印花、波浪、织布格纹、山纹、叶枝、针脚和花轮；单击盖印，按住拖动铺设纹样，每笔只占一次撤销。

- 「编辑图案画布」打开 256×256 原稿，复用左栏画笔、剪纸、几何、笔刀、极简锚点和精细矢量工具。原稿拥有独立撤销历史，应用后保留画布内的边距；原稿文档仍可继续编辑或保存。
- 「图案与色彩」可采集当前图层的可见矢量轮廓，整体调色、逐色替换、缩放和描边。
- 「散布笔刷」可精确设置尺寸、间距、角度、跟随路径旋转，以及轻度横向、大小和角度随机性。
- 笔画预览按比例缩览；黄色便利贴使用实际参数试印，与文档历史独立。工作台关闭后仍可在画布上盖印。
- 保存或另存副本后，图案及参数进入本机浏览器图章库；导出/导入 JSON 可备份或迁移。修改内置图章会保存为个人副本。
- 图章库提供基础纹样、白俄罗斯几何纹样、个人图章分组及搜索。经典示例组包含从用户参考图提取的 16 个矢量纹样，中文名用于检索。
- 悬停可预览落点和实际尺寸；参数支持数值输入与撤销调整。保存后自动定位到个人图章，切换图章会暂存未保存草稿。
- 工作台上方「图章 / 织带」切换绘制方式。任意图章都能成为织带的重复单元；「织带示例」提供蓝印花、双波纹、棋格、山纹四套配方。
- 「织带编排」支持 1–6 行图章、行距、隔行错位和自动带宽；两侧锁边可选直针、交叉针、锯齿针，并设置线色、线宽、深度、间距及距带边距离。跳色支持按列、按行、棋盘循环，可选择替换原色、2–6 个循环色和每几格换色，保留其他图案颜色。
- 织带沿拖动路径生成连续底带、边线及按距离排列的纹样。带宽与纹样尺寸独立控制；关闭底带即可绘制透明纹样序列。织带始终跟随路径转向，整笔一次撤销，保存图章时同时保存织带配方。

图章输出为原生矢量色块，继续参与剪裁、图层颜色/边界同步、矢量编辑与现有导出流程。当前沿路径重复排列图案，不对单个图案做弯曲变形。采集仅提取矢量轮廓和色彩，不烘焙纸纹、阴影和透明度；可在目标图层统一配置纸张质感。

## 素材与色彩工作流

右栏收敛为「图层 / 素材 / 色彩 / 参考」。物件作为图层页的二级页；素材页按「图章 / 织带 / 布料 / 套装」分栏，画笔设置不再重复展示整个素材库。图章展示单个图案，织带展示连续条带；「从图章制作」可复用任意图章。个人图章转为织带后保存为独立配方，保留原图章。

- 选中对象或精确色块后，顶部或右键「收为图章」保存实际可见轮廓、颜色和比例；双击库中素材可在普通画布编辑原稿。
- 「色彩」支持命名方案、参考原色与制作色、用途角色、锁定、排序、灰度检查、变体和收藏，JSON/GPL 导入导出。作品方案随项目文件携带，未保存草稿有本机恢复记录。
- 「参考取色」可导入照片、调用作品参考图或项目布料，框选区域、排除背景、手动补取强调色，再提取 4–16 色。文化归属和参考来源由作者记录。
- 「换色」先展示原色到目标色的映射，再应用到选中图层或作品；颜色交换一次性读取原始颜色，不会连锁覆盖。锁定图层不改色。矢量纹样保留配方，位图像素不参与这种换色。
- 图片布料支持 PNG/JPEG/WebP，原图在项目中共享；纸片轮廓和内部图片有独立变换，支持等比缩放、旋转、移动、单张/平铺/镜像平铺。布料受轮廓和镂空裁切，PNG/SVG/Godot 导出保持一致。导入时最长边缩至 2048 像素，保持比例。
- 新绘制的图章、织带笔画保留素材版本、配方、中心路径和独立对象变换。在素材页展开「本图层纹样笔画」可修改配方或路径，再生仍保留后续剪裁顺序。「展开」转成普通图形；直接编辑个别色块时仅解除受影响笔画的配方关系。
- 图片布料暂不能转为矢量图章；上层布料也不能向下合并，界面会说明原因，防止图片静默丢失。复制矢量纹样仍保留配方。
- 素材「套装」可新建锁定素体的普通画布模板，衣服、鞋子、头饰三类部件分别试穿、归类和保存搭配。Godot manifest 包含三分类、有效套装引用及色彩方案。尚不包含骨骼、多姿态自动适配或完整小游戏关卡系统。
- 名称双击编辑；数字可滚轮微调、横向拖动或双击输入，Shift 加快十倍，也支持方向键和 Enter。图案预览与素材缩略图双击进入原稿编辑。色卡仅在选中色上展开编辑项，常用操作使用图标与悬停提示。
- 设置「绘制反馈」提供轮廓预览与即时填充。剪纸、几何形、多点图形和笔刀共用反馈：轮廓模式只显示虚线边缘，即时模式使用当前选中色且无描边；松手后的剪除/贴花行为不变。偏好在本机保存，普通手绘画笔仍呈现自然笔迹。

## 新建画布

新建窗口提供比例示意、背景色样与纹理小样，可交换宽高或输入 64–4096 px 尺寸。默认空画布，可选附带起始色纸。透明背景的纹理仅辅助预览；实色背景可随合成导出保存。
